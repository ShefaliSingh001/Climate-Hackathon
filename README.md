# ResourceX

A marketplace that matches buyers and sellers of recycled materials (copper, aluminium, steel, plastics, paper, glass, e-scrap) across Australia, starting with NSW.

Built for the COP31 climate hackathon, **Green Industrialisation** priority: raise the global circular material-use rate to at least 15% by 2035.

## Repository layout

| Folder | What lives there | Owner |
| --- | --- | --- |
| `frontend/` | React + Vite + TypeScript UI (map, listings, AI matches, impact) | UI |
| `backend/` | API, dataset and AI matching | Backend |

Each folder has its own README. The frontend's agreed API shapes are in `frontend/API_CONTRACT.md`.
